# 4 = 4 Interactive Puzzle Solver

Interactive terminal tool and solver engine for the **4 = 4** math puzzle.

## Quick Start

### 1. Launch Interactive Mode
```bash
node interactiveTerminal.js
```

### 2. Run Direct Solve Mode
```bash
node interactiveTerminal.js 1111
node interactiveTerminal.js 2222 --disallow "b"
```

### 3. Run Unit Tests
```bash
node test_solver.js
```
