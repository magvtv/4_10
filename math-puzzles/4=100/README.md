# 4 = 100 Interactive Puzzle Solver

Interactive terminal tool and solver engine for the **4 = 100** math puzzle.

## Quick Start

### 1. Launch Interactive Mode
```bash
node interactiveTerminal.js
```

### 2. Run Direct Solve Mode
```bash
node interactiveTerminal.js 5555
node interactiveTerminal.js 2525 --disallow "b"
```

### 3. Run Unit Tests
```bash
node test_solver.js
```
