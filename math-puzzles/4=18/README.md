# 4 = 18 Interactive Puzzle Solver

Interactive terminal tool and solver engine for the **4 = 18** math puzzle.

## Quick Start

### 1. Launch Interactive Mode
```bash
node interactiveTerminal.js
```

### 2. Run Direct Solve Mode
```bash
node interactiveTerminal.js 2333
node interactiveTerminal.js 3346 --disallow "b"
```

### 3. Run Unit Tests
```bash
node test_solver.js
```
