# 4 = 24 Interactive Puzzle Solver (The 24 Game)

Interactive terminal tool and solver engine for the **4 = 24** math puzzle.

## Quick Start

### 1. Launch Interactive Mode
```bash
node interactiveTerminal.js
```

### 2. Run Direct Solve Mode
```bash
node interactiveTerminal.js 1346
node interactiveTerminal.js 6490 --disallow "b"
```

### 3. Run Unit Tests
```bash
node test_solver.js
```
